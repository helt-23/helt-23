## 👨‍💻 Sobre mim

Sou estudante de **Engenharia de Software** na Universidade Federal do Sul e Sudeste do Pará (Unifesspa) e atuo na intersecção entre o desenvolvimento de software e o design de interfaces. Meu foco principal é a construção de sistemas escaláveis e interfaces intuitivas, aplicando rigorosamente os princípios **SOLID** e **Clean Architecture** para garantir códigos limpos, modulares e de fácil manutenção.

---

## 🚀 Destaques e Projetos

*   **SIRLAB:** Coautor do sistema com registro oficial de propriedade industrial no **INPI (BR512025003833-0)**. Atuei na liderança do desenvolvimento do frontend e idealização de todo o UI Design da plataforma.
*   **Concilia:** Desenvolvedor principal e arquiteto de um sistema completo de gestão financeira. O projeto abrange desde o design de interface até a construção de um backend robusto estruturado em Spring Boot.
